# Мультисекундомер — приложение для Android

Нативная обёртка вокруг той же страницы, что и веб-версия. Никакого
дублирования логики: секундомеры, круги, архив и выгрузка в Excel живут в
[`app/index.html`](../app/index.html), а Java-часть отвечает только за то,
чего страница не может сама — файлы, «поделиться», экран и кнопка «назад».

## Что внутри APK

- `assets/index.html` — страница, собранная из `app/index.html`
- `assets/fonts/` — Onest, JetBrains Mono, Unbounded (подмножества
  кириллица + латиница, 6 файлов)
- `assets/vendor/xlsx.full.min.js` — генератор `.xlsx`

Всё лежит внутри приложения, поэтому **разрешение на интернет не
запрашивается вообще** и приложение полностью работает офлайн.

Страница отдаётся не с `file://`, а по адресу
`https://appassets.androidplatform.net/assets/` через `WebViewAssetLoader`.
Это даёт ей полноценный безопасный источник, и данные в `localStorage`
считаются постоянными, а не временными.

## Сборка

Собирает GitHub Actions: [`.github/workflows/android.yml`](../.github/workflows/android.yml).
Запускается при каждой правке в `android/` или `app/index.html`, а также
вручную кнопкой **Run workflow** на вкладке Actions. Готовый файл лежит в
артефакте сборки `multistopwatch-apk`.

APK подписан отладочным ключом — для установки на свой телефон этого
достаточно, для публикации в Google Play нужен свой ключ.

Локально (нужны JDK 17 и Android SDK):

```bash
cd android
gradle assembleDebug
```

## После правки страницы

`app/index.html` — источник и для веб-версии, и для APK. Изменив её, соберите
ассеты заново, иначе в приложении останется старая версия:

```bash
powershell -ExecutionPolicy Bypass -File android\sync-assets.ps1 -SkipDownload
```

Без `-SkipDownload` скрипт заодно перекачает шрифты и SheetJS.

## Установка на телефон

1. Скачать `app-debug.apk` из артефакта сборки.
2. Перекинуть на телефон (кабель, облако, мессенджер).
3. Открыть файл; Android спросит разрешение ставить приложения из этого
   источника — разрешить.

Минимальная версия — Android 10. Она нужна для `MediaStore.Downloads`,
через который таблица кладётся в общую папку «Загрузки» без запроса
разрешений на файлы.

## Мост в систему

Страница видит объект `AndroidHost`, когда работает внутри приложения:

| Метод | Зачем |
|---|---|
| `saveFile(имя, base64, mime)` | кладёт `.xlsx` в «Загрузки», возвращает `ok` или текст ошибки |
| `shareFile(имя, base64, mime)` | открывает системное меню «Поделиться» |
| `keepAwake(вкл)` | не гасит экран, пока идёт хотя бы один секундомер |

Плюс `window.__androidBack()` — кнопка «назад» сначала закрывает открытый
лист внутри страницы и только потом выходит из приложения. В браузере
`AndroidHost` не существует, и все эти ветки просто не выполняются.
