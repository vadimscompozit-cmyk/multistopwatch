# Секундомер → Excel

Две версии:

- **Компьютер** — `stopwatch.py`, описан ниже.
- **Телефон, веб** — [`app/`](app/README.md): много секундомеров в одной
  сессии, сохранение переживает перезагрузку телефона, экспорт в Excel.
- **Телефон, Android** — [`android/`](android/README.md): то же приложение в
  виде APK, работает офлайн. Собирается в GitHub Actions.

## Версия для компьютера

Секундомер на Python (tkinter), который создаёт файл `.xlsx` в момент первого
старта и дописывает каждый круг сразу на диск.

## Запуск

Двойной клик по `Секундомер.bat` либо:

```bash
python stopwatch.py
```

Нужен `openpyxl` (уже установлен):

```bash
pip install openpyxl
```

## Как работает

- **Старт** — создаётся файл `записи/секундомер ГГГГ-ММ-ДД ЧЧ-ММ-СС.xlsx`.
- **Круг** — строка добавляется в таблицу и файл тут же перезаписывается,
  поэтому данные не теряются при сбое или закрытии окна.
- **Сброс** — следующий старт начнёт новый файл, старый остаётся нетронутым.
- Если файл открыт в Excel, запись ставится на паузу с предупреждением в
  строке состояния и возобновляется автоматически, как только файл закроют.

Горячие клавиши: `Пробел` — старт/пауза, `Enter` — круг, `Ctrl+R` — сброс.

## Колонки таблицы

`№`, `Время круга`, `Общее время`, `Круг, сек`, `Всего, сек`, `Время суток`,
`Комментарий`. Числовые колонки в секундах — для формул и графиков; внизу блок
итогов: количество кругов, общее время, средний, самый быстрый и самый
медленный круг.
