# Мультисекундомер (мобильная версия)

Одна страница `index.html` без сборки и зависимостей, кроме двух CDN:
Google Fonts и SheetJS (генерация `.xlsx` прямо в телефоне).

Опубликовано как Artifact:
<https://claude.ai/code/artifact/89408316-4d15-4d90-8ed0-0f2adc25ed19>

## Возможности

- Сколько угодно секундомеров в одной сессии, работают одновременно и независимо.
- Круги с комментарием к каждому; самый быстрый круг подсвечивается.
- Дата и время создания секундомера и каждого круга — на экране и в выгрузке
  (в `.xlsx` это настоящие даты, а не текст: работают сортировка и фильтры).
- «Запустить все» / «Остановить все» — общая точка отсчёта для всей сессии.
- «Новая сессия» отправляет текущую в архив (до 40 сессий), оттуда её можно
  выгрузить в Excel в любой момент.
- Экспорт: скачать `.xlsx`, поделиться файлом через меню телефона, скопировать
  таблицу в буфер. Один лист «Замеры» сплошной таблицей: строка секундомера
  («итог»), под ней его круги отдельными строками, дальше следующий секундомер.
  Имя секундомера повторяется в каждой строке, сверху включён автофильтр.

## Как устроено сохранение

Всё состояние лежит в `localStorage` (ключ `multistopwatch.v1`) и пишется после
каждого действия. Время считается не тиками, а от меток `Date.now()`:
у секундомера хранятся `accumulated` (накоплено) и `startedAt` (метка запуска),
поэтому запущенный секундомер продолжает идти, пока приложение закрыто,
телефон перезагружается или пропала сеть — при следующем открытии он покажет
корректное время.

## Установка на телефон

Открыть ссылку → меню браузера → «На экран «Домой»» (iOS Safari) или
«Добавить на главный экран» (Android Chrome). Появится иконка, приложение
откроется без адресной строки.

Ограничение: страница хостится на claude.ai, поэтому для **первого открытия**
нужен интернет — офлайн-запуск появится на шаге с APK. Данные при этом всегда
локальные.

## Дальше: APK

Логика полностью в этом файле, поэтому обёртка в нативное приложение — это
Capacitor поверх той же папки:

```bash
npm create @capacitor/app
npx cap add android
npx cap sync
npx cap open android
```

Понадобится Node.js + JDK 17 + Android SDK. `webDir` указывает на папку с этим
`index.html`; ничего в коде менять не нужно, кроме выгрузки файла — в APK
вместо `claude.use("downloads")` сработает ветка с `URL.createObjectURL`,
которая уже написана.
